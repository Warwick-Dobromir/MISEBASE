## 3. 关键规则

### 3.1 MIME/大小异常

- 默认全部失败，不自动生成 `PARTIAL`；
- 不自动修改数据库中的 MIME/大小；
- 只有用户明确选择“保留异常继续”才生成 `PARTIAL`；
- 记录字段：`image_asset.id`、文件路径、异常类型、预期 MIME/大小、实际 MIME/大小；
- 其他异常分类（缺失/损坏/孤立）保持原规则，未删除。

### 3.2 两次确认

| 阶段 | 确认目的 | 不确认的后果 |
|---|---|---|
| 备份阶段第一次确认 | 是否在异常存在时生成 `PARTIAL` | 不生成 `PARTIAL`；默认失败 |
| 恢复阶段第二次确认 | 是否用该 `PARTIAL` 替换当前数据 | 不替换当前 DB/附件；可取消 |

两次确认独立，不能复用、跳过或默认同意。
