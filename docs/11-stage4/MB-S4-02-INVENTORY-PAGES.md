# MB-S4-02 库存页面说明

**文档编号**：MB-S4-02
**版本**：`1.0.0`
**状态**：`Review`
**日期**：2026-11-05
**范围**：`feature:inventory` 页面、路由、状态与交互

---

## 1. 路由

| 路由 | 页面 | 入口 |
|---|---|---|
| `inventory` | 库存总览 | N1 底部“库存” |
| `inventory/product/{productId}` | 商品详情 | 总览商品行 |
| `inventory/ledger` | 库存流水 | 总览“流水” |
| `inventory/movement/receipt` | 入库 | 总览“入库” |
| `inventory/movement/issue?batchId=` | 出库 | 商品详情批次“出库” |
| `inventory/movement/adjust?batchId=` | 盘点调整 | 商品详情批次“调整” |
| `inventory/plan` | 需求汇总/缺口/采购清单/记录回放 | 总览“需求计划” |

扫码底部入口仍为占位，不新增 `feature:scan`。

---

## 2. 总览

- 标题、商品总数、搜索框、“仅看缺货”筛选；
- 商品行：商品名、食材名、在手/预留、位置、批次数、最近到期、可用量；
- 可用为 0 显示“缺货”徽标；有预留时显示预留徽标；
- 顶部动作：入库、流水、需求计划；
- 点击商品进入详情，选择具体批次后再出库/调整。

**状态**：`InventoryOverviewUiState`，搜索与筛选在已加载行上完成，不重复查库。

---

## 3. 商品详情

- 商品名、食材名、全部批次可用合计；
- 每个批次：批次号（缺失时显示批次 ID 前 8 位）、位置、到期日、可用量；
- 批次动作：出库、调整；
- 流水区：类型、时间、变化量、变动后余额；
- 关联菜谱：当前使用该食材的启用菜谱名称（读取时计算，不新增表）。

**状态**：`InventoryDetailUiState`；`ON_RESUME` 时刷新，保证从出库/调整返回后余额更新。

---

## 4. 入库

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 来源 | 是 | 商品 / 食材 |
| 商品或食材 | 是 | 选食材时按需创建库存商品 |
| 数量、单位 | 是 | 同维度按基准因子换算到商品库存单位 |
| 批次号 | 否 | 保存为 `batch_code` |
| 到期日 | 否 | `YYYY-MM-DD`；格式错误拒绝 |
| 位置 | 否 | 为空时使用默认储藏位置 |

确认后：创建余额为 0 的批次 → 追加 `PURCHASE_RECEIPT` 流水 → 余额变为入库量。批次与流水同一事务。

---

## 5. 出库

字段：批次、数量、单位、原因（领用/损耗/其他）、备注。

- 数量先换算到批次库存单位；
- 超过“可用（在手 − 预留）”返回 `CUL-INV-003`，显示缺口；
- 流水类型：领用→`PRODUCTION_ISSUE`，损耗→`WASTE`，其他→`ADJUSTMENT_OUT`；
- 不创建预留（MB-D-014 默认模式）。

---

## 6. 盘点调整

字段：批次、实盘数量、单位、备注。

- 差额 = 实盘 − 在手；正数 `ADJUSTMENT_IN`，负数 `ADJUSTMENT_OUT`；
- 差额为 0 拒绝；
- 实盘低于已预留量拒绝；
- 不直接改余额，必须经流水。

---

## 7. 流水

- 行：类型、时间、变化量、商品/食材/位置、变动前→后余额、来源类型/ID；
- 类型筛选：全部/入库/出库/调整；
- 关键字：商品、食材、位置、来源 ID；
- 只读，不提供修改/删除入口。

---

## 8. 需求计划与采购清单

见 [MB-S4-03](MB-S4-03-REQUIREMENT-GAP.md) 与 [MB-S4-04](MB-S4-04-PURCHASE-LIST.md)。

## 9. 视觉与可访问性

- 沿用 MB-D-008 方向 A：暖中性底、Orange 强调、线性图标；
- 使用 `CulinarySpacing`、`CulinarySizes` 与既有组件（`ArchiveListItem`、`SectionHeader`、`QuantityText`、`StatusBadge`、`ErrorBanner`、`EmptyState`、`LoadingRows`）；
- 关键操作按钮文字明确（“确认入库/出库/调整”），颜色不是唯一状态载体；
- 搜索、筛选、错误、空状态均有文字说明。

---

## 10. 已知限制

- 商品由食材首次入库自动创建，本阶段不做完整商品主数据编辑；
- 多商品/多包装时默认使用第一个启用商品；
- 位置默认创建“默认储藏”，本阶段不做位置管理页面；
- 出库/调整从批次进入，总览不提供跨批次批量出库。
