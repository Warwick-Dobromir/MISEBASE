## 1. 信息架构

```text
顶栏：[返回] 页面标题                         [设置]
内容：NavHost
底栏：[酱汁] [食材] [菜谱] [库存] [扫码]
```

- 五个底部入口顺序固定，不允许增删/重排；
- 设置不占底部栏；
- 三大知识库保持独立一级入口，不合并为统一档案页；
- 扫码保留底部一级入口。

## 3. 行为

- 切换底部入口：`popUpTo(start)` + `saveState` + `launchSingleTop` + `restoreState`，保留栈状态；
- 详情/编辑：底部栏隐藏，顶栏显示返回；
- 返回键：先关闭弹层（Compose Dialog 自身处理）→ 再返回上一页 → 最后退出；
- 库存、扫码、设置页只显示占位说明，不提供业务操作。

## 4. 启动页与首页

- **当前启动页为 N1 第一个入口「酱汁」**；本阶段不修改启动逻辑；
- **UI-07 已确认**（2026-11-04，负责人电子确认）：**后续新增独立首页，当前不实现；不改变 N1 五入口信息架构**；
- 独立首页属于全局导航与信息展示页面，**不新增底部一级入口**；
- **当前不得修改路由或启动逻辑**；独立首页为后续待开发事项，具体内容/布局/交互由后续独立 UI 设计任务确定；
- 本决定**不构成提前启动首页开发的授权**。
