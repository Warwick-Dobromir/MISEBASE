## 2. 酱汁库（feature:sauces）

### 2.1 路由

| 页面 | 路由 | 参数 |
|---|---|---|
| 列表 | `sauces`（底部一级） | — |
| 详情 | `sauces/{sauceId}` | 酱汁 ID |
| 编辑 | `sauces/{sauceId}/edit` | `new` 表示新建 |

### 2.2 列表

- 展示：名称、分类（空显示「未分类」）、在用/归档；
- 操作：新建、进入详情；
- 空状态：说明为什么空 + 「新建第一个酱汁」。

### 2.3 详情

- 头部：名称、状态、分类；
- 当前版本：版本号、产量 + 单位、已发布标记；
- 操作：编辑（进入新版本）、发布最新草稿（`vN`）；
- 组成：行号顺序、目标名称、数量 + 单位、可选标记；
- 版本历史：版本号、状态（草稿/已发布/已取代）、当前标记、产量。

### 2.4 编辑器

- 字段：名称、分类/家族、标准产量 + 单位、组成行（食材、数量、可选）；
- 组成行单位取食材默认单位（缺省取第一个单位）；
- 保存：先写档案，再写新版本；
- 编辑已发布酱汁：提示「已发布版本不可修改」，保存生成新版本号；
- 发布：保存后立即发布，或从详情发布草稿。

### 2.5 版本与不可变

- 已发布版本内容不可修改（数据库触发器 + 领域 `VersionStatus`）；
- 同一酱汁仅一个当前版本（部分唯一索引）；
- 重复发布返回 `CUL-CON-001`。

### 2.6 已知限制

- 编辑器当前只新增/编辑食材组成行；若历史数据含子菜谱/子酱汁组成行，编辑保存不会保留（当前无导入入口）。
- 子酱汁嵌套编辑不在 Stage 3 范围。

## 3. 食材库（feature:ingredients）

### 3.1 路由

| 页面 | 路由 |
|---|---|
| 列表 | `ingredients`（底部一级） |
| 详情 | `ingredients/{ingredientId}` |
| 编辑 | `ingredients/{ingredientId}/edit`（`new` 为新建） |

### 3.2 列表

- 展示：名称、分类（空显示「未分类」）、默认单位符号；
- 操作：新建、进入详情。

### 3.3 详情

- 头部：名称、状态、分类；
- 默认单位（名称 + 符号）；
- 描述（有则显示）；
- 换算依据：条数、`from → to × factor`、备注；无换算时说明「不猜数」；
- 操作：编辑、归档（二次确认，说明归档影响）。

### 3.4 编辑器

- 字段：名称、分类、默认单位、描述（多行）；
- 校验：名称必填/≤120；分类≤60；描述≤500；
- 保存成功后返回列表。

### 3.5 已知限制

- 别名的创建/编辑、换算的新增/删除不在 Stage 3（读取展示已支持）；
- 归档为软删除语义，不提供物理删除入口。

## 4. 菜谱库（feature:recipes）

### 4.1 路由

| 页面 | 路由 |
|---|---|
| 列表 | `recipes`（底部一级） |
| 详情 | `recipes/{recipeId}` |
| 编辑 | `recipes/{recipeId}/edit`（`new` 为新建） |

### 4.2 列表

- 展示：名称、分类、在用/归档；
- 操作：新建、进入详情。

### 4.3 详情

- 头部：名称、分类标记、状态；
- 当前版本：版本号、产量 + 单位、基准份数；
- 操作：编辑、发布最新草稿；
- 组成：目标名称、类型（食材 / 子菜谱 vN / 子酱汁 vN）、数量 + 单位、可选标记；
- 配方展开：
  - 目标份数输入（默认 = 基准份数）+「展开」；
  - 结果标题显示「目标份数 / 基准份数」；
  - 每行食材名、数量、可选标记；底部说明「只做展示，库存/采购在 Stage 4」；
  - 展开失败显示错误码与原因；
- 版本历史：版本号、状态、当前标记、产量。

### 4.4 编辑器

- 字段：名称、分类（5 类）、标准产量 + 单位、基准份数、组成行；
- 组成行来源：
  - 食材：名称、数量、单位、可选；
  - 子菜谱：选择后显示当前版本号，保存/发布时固定版本；
  - 酱汁：选择当前已发布版本，固定 `sauce_version_id`；
- 保存草稿 / 保存并发布；
- 编辑已发布菜谱：生成新版本号，旧版本内容不变。

### 4.5 版本固定

- 新增子菜谱行在草稿中保存为「当前版本」引用；
- 保存草稿或发布时解析为明确版本 ID；发布前做循环校验；
- 已在库中的版本只引用固定 ID，不随「当前版本」漂移。

### 4.6 份数与可选

- `recipe_version.servings` 是基准份数，编辑与详情均使用；
- 展开倍数 = 目标份数 ÷ 基准份数；
- 可选配料在编辑、详情、展开中都有文字标记；缺料默认口径仍按 MB-D-015（Stage 4 计算）。

### 4.7 已知限制

- 含酱汁目标的配方展开返回 `CUL-REP-004`（显式拒绝，不静默少算）；
- 步骤/SOP 编辑、成品标准不在 Stage 3；
- 展开不做需求合并/库存对比/采购清单。

## 5. 状态与错误文案

| 场景 | 文案来源 |
|---|---|
| 列表加载失败 | 页面错误条 + 错误码 |

| 名称重复 | `CUL-CON-001` 对应「名称已存在」 |
| 循环引用 | `CUL-REP-001`「检测到子配方循环引用」 |
| 已发布重复发布 | `CUL-CON-001` |
| 未知错误 | 保留错误码，不伪装成业务错误 |
