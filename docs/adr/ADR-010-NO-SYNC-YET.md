# ADR-010：本阶段不做云同步

**状态**：Proposed
**版本**：`0.1.0`
**日期**：2026-11-04
**决策者**：首席架构师 / 项目负责人
**关联**：D-014、P01、A02

## 背景

产品定位为单用户、离线优先、Android 本地数据；任务书明确不引入云账号、多人协作、实时同步。

## 决策

- 不实现账号、云数据库、实时同步、多人协作。
- 数据模型保留低成本扩展缝：
  - UUID 主键；
  - `created_at` / `updated_at`；
  - 软删除 `deleted_at`；
  - Repository 端口。
- 不预建 outbox、冲突解决表、服务端代码。
- 未来若做同步，另立 ADR 与安全评审。

## 理由

- 当前需求不需要同步；提前做会显著增加复杂度和故障面。
- 离线单机已经能完成全部核心流程。
- 保留 UUID/时间戳/软删除足以支持未来增量同步。

## 后果

- 换机只能靠备份/恢复，不能自动同步。
- 多设备并行编辑不支持。
- 未来加同步时仍需处理冲突、身份、加密、配额。

## 替代方案

- 现在就做云同步：超出范围，且违反离线优先。
- 文件级同步（网盘）：冲突不可控，不作为产品能力。

## 复审条件

- 项目负责人明确要求多设备/多人；
- 备份恢复无法满足换机需求；
- 有明确的同步范围与隐私方案。
